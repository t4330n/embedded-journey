PA0 핀 실험실

칩 안에는 PA0를 저항을 거쳐 3.3V에 연결하는 스위치(①)와 저항을 거쳐 GND에 연결하는 스위치(②)가 들어 있어요. 스위치와 바깥 연결을 바꾸면서, 선마다 전압이 어떻게 되는지 색으로 확인해 보세요.

어제 한 실험
칩 안 스위치 (PUPDR)
점퍼선 끝 (바깥)

칩 안을 들여다보면

3.3V 0V 정해지지 않음 (어디에도 연결 안 됨) 전류가 흐르는 길

상태

PA0 전압?
칩이 읽은 값 (IDR)?
흐르는 전류0
LD4꺼짐

세 줄 정리

핀 값 = 핀이 연결된 곳의 전압

3.3V에 연결되면 1, GND에 연결되면 0, 어디에도 연결 안 되면 정해지지 않아요(플로팅).

풀업 = 저항을 거쳐 3.3V에 연결

스위치 ①은 위쪽 3.3V에만 이어져 있어서 풀업만 할 수 있어요. 스위치 ②는 GND에만 이어져 있어서 풀다운만 할 수 있어요.

저항은 "져 주는" 연결

바깥에서 선으로 반대쪽에 바로 이으면, 선이 이기고 저항이 전압을 전부 맡아요. 그래서 합선 없이 값만 바뀌어요.

칩 안 풀업·풀다운 저항은 대략 40kΩ으로 계산했어요(실제 값은 데이터시트 참고). 1로 읽히는 전압·0으로 읽히는 전압의 경계도 대략값이에요.
